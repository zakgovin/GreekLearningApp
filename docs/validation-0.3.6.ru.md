# Проверка версии 0.3.6

Пропуск убран из начального аудирования и написания. Он остаётся только в продвинутом аудировании и произношении. При пустом вводе написания сообщение «Введите ответ» не предлагает пропуск и не меняет прогресс.

assembleDebug, все 62 Android/JVM-теста и lintDebug завершились успешно. Новый сценарий проверяет четыре режима, отсутствие/наличие кнопки по правилу, сообщение пустого ввода и отсутствие начисления/штрафа. Сценарии выполнялись в Robolectric API 28, без физического телефона. Подпись действительна, applicationId и ключ сохранены, versionCode=20, versionName=0.3.6.
