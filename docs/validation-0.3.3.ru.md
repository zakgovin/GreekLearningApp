# Проверка версии 0.3.3

Неверная пара в сопоставлении подсвечивает обе выбранные ячейки красным на 500 мс. Затем на том же экране восстанавливаются обычный вид и возможность выбрать новую пару. Ранее решённые пары остаются зелёными; ошибка по-прежнему снимает по 1 пункту у обоих слов.

assembleDebug, все 58 Android/JVM-тестов и lintDebug завершились успешно. Новые сценарии проверяют красный фон обеих кнопок, временную блокировку, возврат обычного RippleDrawable через 600 мс виртуального времени, сохранение зелёной найденной пары, отсутствие повторного штрафа при быстрых нажатиях, возможность верной попытки и последующее озвучивание. Выход во время подсветки не возвращает пользователя с главного экрана отложенным callback; продолжение восстанавливает незаблокированные кнопки и единственный учтённый штраф. Android-сценарии — Robolectric API 28, без физического телефона.
