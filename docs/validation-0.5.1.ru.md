# Проверка версии 0.5.1

Исправлен дневной счётчик: одно завершённое задание со словом учитывается один раз. Ошибка с повторным выбором в MATCH/TO_RU/TO_EL/LISTEN_EASY даёт ноль до окончательного правильного ответа. В WRITE/LISTEN_HARD/SPEAK ошибочный ответ или пропуск завершают задание и учитываются один раз. Другой слот или сессия с тем же словом считается заново. Проценты знаний и штрафы за настоящие ошибки сохраняют прежние правила.

Добавлены practiceKey и daily_completions. Новый технический attemptId с прежним ключом завершённого задания не начисляет дневной плюс и не меняет проценты. Импорт также не удваивает дневной итог. Миграция 5→6 пересчитывает дневные количества из журнала по исправленному определению, сохраняя цели, нулевые дни, исходные попытки, даты и проценты. Пакетное чтение журнала не удерживает изменяемый курсор во время обогащения старых payload. Для старых записей без ключа задания сохраняется учёт допустимых отдельных попыток, без объединения законных повторов слова.

Убраны кнопки истории и добавления слова на главной странице. История открывается виджетом «Сегодня». В словаре добавлен плюс в правом верхнем углу; после добавления/закрытия возврат в словарь. При выборе тренировки показано количество слов выбранного режима; соседняя иконка открывает настройки, большой кнопки больше нет. Смена режима и возврат из настроек обновляют число; сама тренировка использует сохранённое значение.

assembleDebug, 93 Android/JVM-теста и lintDebug прошли успешно. Регрессии: пользовательский сценарий 110 завершений + 4 неверные пары восстанавливается из 118 в 110; дневная цель 200 и проценты при этом сохраняются. Проверены все семь режимов, повтор слова в новом задании, повторная отправка с новым ID через полночь и после восстановления, реальный UI ошибочной пары с последующим исправлением обеих пар, ошибочный выбор во всех трёх режимах выбора ответа, callback TTS и восстановление. Дополнительные UI-тесты проверяют плюс словаря, ввод и сохранение слова, отсутствие лишних кнопок, переключение режима, соседство числа и иконки настроек и запуск фактически выбранных 25 слов после сохранения. Ранее непустой по попыткам день без завершений остаётся в истории как нулевой.

Native Graphics-рендеры главного экрана, словаря и выбора упражнения на 360×800/API 28 просмотрены. Физическое Android-устройство не использовалось. Словарь, стабильные ID, справочные карточки и Learning.kt совпадают с предыдущим коммитом; миграционные тесты подтверждают сохранение баллов и очереди повторов. Подпись совпадает с APK 0.5.0.
