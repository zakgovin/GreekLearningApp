# Полные карточки слов — 0.4.0

Карточки доступны из малой карточки в словаре и строки итогов тренировки. Закрытие крестиком или системной кнопкой «Назад» возвращает исходный фильтр, поиск, страницу и прокрутку. При пересоздании Activity восстанавливается открытая карточка. Просмотр не меняет прогресс, очередь закрепления или результаты завершённой тренировки.

Контент хранится отдельно в `app/src/main/assets/word-details.json` с привязкой к прежним ID. База данных, версия словаря, допустимые ответы и сами 1724 записи не менялись. Для пользовательских слов без подготовленного пакета показываются перевод, прогресс и сообщение об отсутствии примеров; придуманные склонения им не присваиваются.

## Примеры

Готовые греко-русские фразы взяты из Tatoeba Challenge v2023-09-26, файлов ell-rus (test и dev), опубликованных Helsinki-NLP. Сохранены исходные тексты обеих сторон; каждая цитата содержит URL исходного файла и номер строки. Набор фиксирован в `data/word-details/tatoeba-*.tsv`, README источника — рядом. Авторство: участники Tatoeba; греко-русские предложения распространяются по CC BY 2.0: https://creativecommons.org/licenses/by/2.0/ . Исходный корпус: https://tatoeba.org/ ; зеркало: https://github.com/Helsinki-NLP/Tatoeba-Challenge/tree/master/data/release . Примеры не использованы для обучения модели перевода.

Отбираются короткие фразы (2–9 слов, ограничение длины текста), с лексикой преимущественно из глоссария A2 и совпадающим русским значением. Это эвристика простоты, не частотный рейтинг и не официальная сертификация CEFR. У одного слова максимум три примера. Если подходящей цитаты нет, добавляется короткий учебный пример с явной пометкой. Такие примеры не выдаются за цитаты: часть отредактирована в `editorial-examples.json`, часть строится из базовой формы и уже известного перевода по простым моделям. Русское спряжение в этих моделях помогает формировать pymorphy3. Полная независимая лингвистическая вычитка всех карточек не проводилась.

## Формы

Источник учебной морфологии — библиотека Krzysztof Hilman **Modern Greek Inflexion 2.0.7**, MIT: https://github.com/PicusZeus/modern-greek-inflexion . Это генерация по словарю и корпусным правилам, не ручная выписка из официального экзаменационного пособия. Лицензия сохранена рядом с данными. UniMorph и словарь Триандафиллидиса также проверялись при поиске источников, но их тексты не включены в этот пакет.

- Существительные: именительный, родительный, винительный и обращение; единственное и множественное число. У имён собственных для A2 оставлено единственное число. Дательный падеж не добавлен. Составные названия обрабатываются с согласованием определений.
- Прилагательные: три рода, единственное/множественное число, именительный падеж. Без степеней сравнения.
- Глаголы: шесть лиц; настоящее, прошедшее завершённое (αόριστος), простое будущее с θα. Если глагол не имеет таких форм, используется доступная форма: например, у είμαι — παρατατικός и θα είμαι. Пассивные и возвратные словарные леммы сохраняют свой залог. Сложные времена и причастия не показываются. Знак «—» отмечает неупотребительную форму.

## Воспроизведение

Готовый JSON уже включён в Git и APK: для сборки Android Python-зависимости контента не нужны.

Для повторной подготовки установите `data/word-details/requirements.txt` в отдельное venv. У modern-greek-accentuation 1.0.7 есть лишние импорты тестовых модулей CPython, которых нет в сокращённой облачной установке: в установленном `accentuation.py` замените `from _ctypes_test import func` на `from typing import Callable as func` и удалите неиспользуемый `from _testcapi import raise_exception`. Это совместимость окружения, не изменение правил ударения. Затем:

```
python tools/build_word_details.py
python tools/test_word_details.py
python tools/test_a2_dictionary.py
```

Иконка αω строится в `tools/build_icon.py` из контуров DejaVu Sans; лицензия шрифта сохранена в `data/word-details/dejavu-copyright.txt`. Используется бело-голубой знак на тёмно-синем фоне, адаптивная маска Android и монохромный слой для тематических иконок. Векторные файлы включены в репозиторий.
