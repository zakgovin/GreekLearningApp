# Проверка версии 0.3.0

Итог тренировки — компактная таблица вместо отдельных крупных карточек: греческое слово, текущий процент, цветное изменение; строки от 56 dp, разделители, единое белое основание. Повторяющиеся «Было» и полосы прогресса удалены из визуального представления, прежнее значение остаётся в доступном описании строки. Неизвестная дельта старой сессии обозначается «—» с пояснением.

Глобально уплотнены отступы/заголовки, уменьшены скругления, кнопки плоские с тонкой рамкой и нативным ripple, минимальная область нажатия 48 dp сохранена. Переходы между различающимися экранами/вопросами — прозрачность 0,82→1 и сдвиг 6 dp, 160 мс при обычной системной скорости. Повторная отрисовка того же вопроса после ошибки/подсказки не анимируется. Системное отключение анимаций учитывается. Навигация, начисление и завершение TTS не ждут анимацию.

assembleDebug, все 52 Android/JVM-теста и lintDebug завершились успешно. Новые проверки: нативная отрисовка итогов на 360×800 px при mdpi, все 10 строк высотой 48–72 px, горизонтальные колонки; отсутствие анимации при системном animation scale=0. Сохранены проверки точных процентов, очереди повторов, всех режимов и миграций.

Снимок экрана сформирован реальным Android Canvas в Robolectric Native Graphics и визуально просмотрен: `app/build/reports/ux/summary.png`.
