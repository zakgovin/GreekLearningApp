# Полный глоссарий ΚΛΙΚ A2 в приложении

Версия приложения 0.2.0 содержит 1724 учебные записи. Они покрывают все 1704 лексические статьи присланного PDF; ещё три стартовые записи (τραπέζι, επτά, οκτώ), которых нет в этом глоссарии, сохранены для совместимости. Количество записей отличается от количества статей: мужские/женские названия людей и некоторые местоименные формы разделены, а повторные статьи и значения одной леммы объединены.

Это полный глоссарий именно предоставленного издания, а не утверждение, что он исчерпывает всю лексику экзамена A2. Встроенные русские переводы и разметка подготовлены для приложения по греческому оригиналу и английским значениям. Они не являются официальным русским изданием или независимо сертифицированным переводом.

## Полнота и происхождение

- PDF: 20 физических страниц, статьи на страницах 5–18.
- SHA-256: `0f42030e6d627967387e6a3365aea00ecd3379aa066f4eb6ab73df5c1bec4461`.
- Повторное извлечение из загруженного PDF воспроизвело все 1705 исходных кандидатов в `data/klik-a2.review.json` без расхождений.
- Один кандидат `O, o = όμικρον` является заголовком буквы, исключён из упражнений с явной причиной. Остальные 1704 статьи имеют русские значения, часть речи и ссылки на созданные записи.
- На страницах тела PDF 1727 знаков равенства: 1704 лексические статьи и 23 буквенных заголовка со знаком равенства. Ещё один заголовок, Ζ, ζ, не содержит равенства. Буквенные разделители не считаются словарными словами.

Файл `data/klik-a2/coverage.json` содержит соответствие каждой исходной статьи постоянным идентификаторам, страницу источника, список исключений и статистику. В каждой учебной записи также сохраняются `sourceEntries` и `sourcePages`; они показываются в словаре и сохраняются в резервной копии.

## Подготовка слов

- `data/klik-a2/ru.tsv`: русские значения и части речи для каждого из 1705 кандидатов; один явно помечен heading.
- `data/klik-a2/proper-name-entries.json`: фиксированная разметка имён собственных, независимая от последующего редактирования русского текста.
- `tools/build_a2_dictionary.py`: детерминированная сборка, исправления переноса строк и морфологии, объединение значений, сохранение стартовых ID.
- `app/src/main/assets/a2.json`: готовый встроенный словарь и совместимый файл импорта.
- `app/src/main/assets/a2-version.txt`: версия содержимого для однократной загрузки обновления базы.

Устранены разрывы двух статей с παρακαλώ, нормализованы смешанные латинские/греческие символы, восстановлены полные леммы вместо сокращений наподобие καλ-ός. Варианты спряжения и допустимые альтернативные написания хранятся в `forms`, остальные родовые/числовые формы — отдельно в `inflections`, чтобы не считать любую форму правильным ответом на задание с базовой формой. Распространённые мужские/женские названия лиц — отдельные записи с соответствующими переводами. Формы вроде англ. языка αγγλική γλώσσα / αγγλικά допускаются как альтернативные ответы.

Текст исходного извлечения оставлен неизменным для аудита. Исправления и нормализованные слова применяются в сборщике, а не маскируются изменением исходных кандидатов.

## Сохранение прогресса

Все 60 стартовых идентификаторов сохранены, в том числе для φίλος и φίλη раздельно. Обновление с базы версии 1 до 2 создаёт только служебную таблицу версии словаря. Существующие таблицы слов, прогресса и попыток не удаляются. Новые записи добавляются, встроенные определения обновляются по ID, пользовательские определения не перезаписываются.

Начисления и дроби старых слов остаются прежними. Средний процент на главном экране может стать меньше из-за добавления новых слов с нулевым прогрессом: это не сброс старых результатов. Сохранённые тренировки с прежними ID остаются продолжимыми.

Идентификаторы новых лемм строятся из греческой леммы, части речи, артикля и фиксированной лексической классификации, а не номера строки, страницы или русского перевода. Редактирование русского значения не должно создавать новый ID. Версия всего пакета зависит от содержимого, поэтому обновление определения автоматически приводит к повторному слиянию при следующем запуске.

## Тренировки большого словаря

Варианты ответов по-прежнему одной части речи. Одинаково звучащие/пишущиеся греческие слова и пересекающиеся русские значения не используются как заведомо неправильные варианты. Сопоставление исключает неоднозначные пары и сохраняет лимит пяти пар на экране.

В свободном греческом ответе без подсказок принимаются известные синонимы показанного русского значения из того же грамматического класса. После побуквенной подсказки сохраняется привязка к конкретному слову и длине для правильного расчёта доли зачёта. В продвинутом аудировании принимаются значения совпадающих греческих лемм, которые невозможно различить только на слух без контекста.

Вопросы не требуют ввести финальное восклицание или вопросительный знак: это словарная тренировка, а не пунктуационный диктант. Поиск не требует греческих ударений, но проверка греческого написания сохраняет различие ударений. Словарь показывается страницами по 40 карточек; прогресс и список слов читаются пакетно/кэшируются, чтобы объём глоссария не превращал каждый вопрос в тысячи запросов к базе.

## Воспроизведение и проверка

```sh
python tools/build_a2_dictionary.py
python tools/test_a2_dictionary.py
python tools/gradle_cloud.py :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Изменение словаря — отдельная операция редактирования: после правки TSV/правил сборки нужно пересобрать asset и проверить отчёт покрытия. Обычная установка зависимостей не меняет словарные исходники или готовый asset. Для будущего удаления/объединения лемм, уже выпущенных с постоянными ID, нужна явная миграция ссылок и прогресса, а не простое удаление записи.

С версии 0.3.1 для имён собственных (105 записей) выделена отдельная учебная категория и фильтр. Уточнены названия организаций и географических объектов. `data/klik-a2/stable-ids.json` фиксирует все ранее выпущенные ID, включая алиасы до/после уточнения разметки, чтобы изменение классификации не сбрасывало результаты. Грамматическая часть речи остаётся noun.
