# Проверка версии 0.3.17

Итоговая таблица: слово, изменение (14sp), текущий прогресс (16sp) крайним справа; заголовки переставлены соответственно. «Завершить» и «Новая тренировка» вынесены из ScrollView в нижнюю панель. Список занимает оставшуюся высоту. Системные отступы применяются к общему контейнеру, поэтому кнопки располагаются выше панели навигации Android и не перекрывают последние строки.

Проверка Native Graphics 360×800 расширена до 100 слов. Проверены порядок и относительный размер чисел, доступность обеих кнопок без прокрутки, неизменность их координат при прокрутке до конца, видимость последнего слова выше панели и работа кнопки новой тренировки. Длинные слова могут увеличивать высоту строки для переноса. Скриншот build/reports/ux/summary.png просмотрен.

assembleDebug, 71 Android/JVM-тест и lintDebug прошли успешно. Подпись APK проверена; applicationId и ключ прежние, versionCode=31, versionName=0.3.17. Схема данных не менялась. Android-тесты выполнены в Robolectric API 28; физическое устройство не использовалось.
