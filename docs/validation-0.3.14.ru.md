# Проверка версии 0.3.14

В написании обнаружена строгая проверка только формы без артикля, отдельно в ветке ответа с подсказкой. Обе ветки теперь принимают базовую форму с правильным словарным артиклем существительного или без него. Общий валидатор используется также в произношении. После подсказки по-прежнему требуется целевое слово, а не синоним. Ударения проверяются строго. Число букв для награды не включает артикль; правила подсказок не изменены. Пояснения интерфейса обновлены.

Модульная проверка охватывает три рода, наличие/отсутствие артикля, неправильный артикль и ударение. Новый интеграционный тест вводит «το νερό» без подсказки (+1), затем с одной подсказкой (+0,75), проверяет ожидание озвучивания и отсутствие ошибок. Существующие сценарии ввода без артикля также проходят.

assembleDebug, 70 Android/JVM-тестов и lintDebug прошли успешно. Подпись APK проверена; applicationId и ключ прежние, versionCode=28, versionName=0.3.14. Схема данных не менялась. Android-тесты выполнены в Robolectric API 28; физическое устройство не использовалось.
