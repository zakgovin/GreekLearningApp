# Проверка версии 0.5.0

На главном экране рядом с общим процентом показаны дневное количество слов и цель. История показывает все доступные календарные дни, включая нулевые, страницами по 30 дней. Цель 10–10000, по умолчанию 100, доступна из истории и настроек тренировок. Счётчик может превышать цель; графическая полоса ограничена 100%.

Подсчёт: каждое новое сохранение ответа — по одному за каждое слово в changes. Повторные слова, ошибочные ответы, явные пропуски и ответы с подсказками учитываются; неверная пара даёт два. Callback TTS, восстановление и повторный импорт не добавляют дублей. Запись идемпотентной попытки, дневной счётчик и проценты сохраняются атомарно.

Миграция базы 4→5 создаёт daily_counts/daily_goals и восстанавливает статистику по датированным старым попыткам. У существующих слов, прогресса, сессионных балансов и очереди повторов ничего не удаляется; обновления с баз 1–3 также проверены. У старых попыток первая восстановленная дата фиксируется в localDay. Новые ответы учитываются по времени телефона; границы суток и DST проверены. Главный экран и история обновляются при возобновлении, в полночь и при изменении системной даты, времени и зоны.

JSON-обмен сохраняет dailyGoal/dailyGoalHistory и даты попыток. Проверены повторный импорт без удвоения, восстановление старой копии без новых полей, восстановление цели на более позднюю дату, перенос между часовыми поясами, сохранение исторических целей и отклонение значений за пределами диапазона. Старые записи без достоверной даты не создают выдуманную историю.

assembleDebug, 85 Android/JVM-тестов и lintDebug прошли успешно. Дополнительные сценарии: несколько ответов на одно слово, ошибки/пропуски/полностью подсказанное слово, оба слова неправильной пары, возобновление сессии, поздний callback, локальная полночь и переход летнего времени, миграция без изменения существующих баллов, пустые дни и дневная цель, достигнутая сверх лимита. Native Graphics-рендер главного экрана на 360×800/API 28 с 15000/10000 просмотрен; UI-тест проверяет историю, пагинацию, диапазон настроек и обновление по событию даты. Физическое Android-устройство не использовалось.

Словарь, стабильные ID, справочные карточки и Learning.kt совпадают с предыдущим коммитом. Подпись APK проверена и совпадает с APK 0.4.1. ApplicationId прежний; versionCode=34, versionName=0.5.0. Устанавливать поверх предыдущей версии без удаления приложения и очистки данных.
