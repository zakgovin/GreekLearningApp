# Проверка версии 0.1.4

В сопоставлении максимум пять пар одновременно. Настройка размера всей тренировки (1–100 слов) сохранена; после блока автоматически показываются следующие слова.

assembleDebug, все 28 тестов и lintDebug завершились успешно. Новый сценарий проверяет тренировку из семи слов: сначала пять пар, затем две, итог и однократный зачёт всех семи слов. Дополнительный сценарий моделирует продолжение старого блока из восьми пар с шестью уже найденными: сохраняет зачёт, автоматически пропускает завершённую первую пятёрку и не начисляет повторные очки уже решённым словам. Android-сценарии выполнялись в Robolectric API 28.
