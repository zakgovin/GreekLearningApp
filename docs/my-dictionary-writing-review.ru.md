# Написание в My Dictionary: разбор записи пользователя

Источник: video_2026-10-24_21-55-33.mp4, продолжительность около 88 секунд. Таймкоды — от начала файла. Проверены кадры с шагом четыре секунды и более подробные кадры в местах исправления ответов. Звук отдельно не анализировался. Неизвестное поведение не считается подтверждённым.

## Наблюдаемая последовательность

- 0–4 с: меню тренировок, для написания по переводу выбрано пять слов.
- 4–17 с: русское «спасибо», поле ввода, системная клавиатура. Пользователь переключает русскую раскладку на греческую и набирает слово. На 15 с виден «Ευχαριστώ» на зелёном фоне, к 17 с появляется следующее задание.
- 17–29 с: «Жарко». На 22–26 с введено «ζεστή», перехода нет; пользователь исправляет окончание. На 28 с «Ζεστά» подсвечено зелёным, затем следующее задание. Само отсутствие перехода не раскрывает внутренние правила проверки или штрафов.
- 29–49 с: «справа», постепенный ввод греческого слова; далее переход к «идея».
- 49–73 с: «идея». Написанное «ιδέα» остаётся в поле без перехода. Пользователь пробует «το ιδέα», затем ввод с «Η …». После этого появляется следующее задание. Это указывает на значимость сохранённой формы/артикля в данном примере, но не доказывает универсальное правило для всех существительных.
- 73–85 с: «шестнадцать». На 82 с видно «Δεκαέξι» на зелёном фоне. Затем выход с экрана; итоговая статистика не показана.

## Устройство экрана

Вверху — выход и индикатор прохождения; справа — пиктограммы динамика и настроек. По центру русский вопрос, ниже однострочное поле с очисткой (крестик) и кнопкой «?». Для некоторых слов есть ссылка «Показать примеры», но её содержимое в записи не открывается. Поле и вопрос остаются видимыми над системной клавиатурой.

Успешный ответ подсвечивается зелёным, затем происходит переход. Отдельной кнопки «Проверить» в видимой области нет. По записи нельзя окончательно отличить проверку при вводе от отправки системной клавишей Enter: точный момент нажатий клавиатуры не установлен. Красная ошибка и объяснение ошибки не показаны; Поведение подсказки уточнено пользователем отдельно: каждое нажатие «?» вводит следующую букву ответа, а актуальное правило частичного зачёта описано ниже. По самой записи это действие не было установлено. Правила озвучивания и внутренний расчёт процентов референса не исследованы. Подсказки слов над клавиатурой принадлежат системной клавиатуре, а не доказанно приложению.

## Решения для GreekLearningApp

1. Основной режим — русское значение с контекстом → самостоятельный ввод по-гречески. Это навык «Написание», максимум 25 пунктов на слово.
2. Проверка — явной кнопкой «Проверить» и системным действием IME Done. Неполное слово при наборе не считается ошибкой. Это сознательное проектное решение, не копия неподтверждённой автопроверки оригинала.
3. После отправки: правильный ответ получает текстовое подтверждение и зелёную подсветку; неправильный — понятное объяснение и возможность исправления. Ошибка в ударении показывается отдельно. Неверная отправка даёт −1. Новая самостоятельная попытка без подсказки может дать +1; после раскрытия ответа повторение остаётся без положительного зачёта.
4. Ввод не зависит от регистра, нормализуется в Unicode NFC. Тон и диерезис проверяются. Синонимы и допустимые формы перечисляются явно.
5. Артикль не должен быть скрытым условием: по умолчанию, согласно основной спецификации, проверяется лемма без артикля. Если включено задание «с артиклем», это явно написано рядом с полем; ожидаемый артикль берётся из словаря. Пример из видео не меняет правило автоматически.
6. Кнопка «?» по каждому нажатию вводит одну следующую букву ожидаемого ответа. Приложение хранит число раскрытых букв H и длину ответа N; при правильном завершении награда равна (N − H) / N пункта. Интерфейс показывает оставшуюся награду. Очистка поля не сбрасывает историю подсказок. Примеры до ответа должны скрывать целевое греческое слово; раскрывающий пример считается подсказкой.
7. Во время написания озвучивание целевого слова раскрывает весь ответ и обнуляет награду этой попытки; до ответа такую кнопку лучше не предлагать. Нейтральное озвучивание русского задания — нет. До отправки отключаем запрос автокоррекции и предложений средствами Android, но не обещаем контроль всех сторонних клавиатур.
8. Приложение запрашивает подходящий язык ввода, но не предполагает, что греческая раскладка установлена или переключится автоматически. Предусмотрена справка по включению греческого языка. Поле не перекрывается клавиатурой; поворот и уход в фон сохраняют черновик без начисления очков.
9. Набор слов для сессии остаётся однородным по части речи. Для свободного ввода нет отвлекающих вариантов; контекст устраняет неоднозначность перевода.

## Что проверить при реализации

Правильная лемма; неверный тон; другая форма того же корня; явно допустимый синоним; обязательный/необязательный артикль; очистка; подсказка; Enter и кнопка проверки; повторная отправка; незавершённый ввод; отсутствие греческой раскладки; изменение размеров экрана при открытии клавиатуры. Индикатор прохождения сессии и освоение слова должны оставаться разными величинами.

## Уточнение пользователя: побуквенная подсказка

Это подтверждение пользователя о референсе, отдельно от наблюдений по кадрам. Для новой реализации ожидаемое поведение:

- Первое нажатие открывает первую букву; каждое следующее — ещё одну. Подсказка формирует правильный префикс: неверно набранный текст заменяется этим префиксом. Это правило обработки ошибочного ввода — проектное решение.
- Буква считается графемой после NFC-нормализации: греческая буква с ударением или диерезисом не разделяется на самостоятельные шаги. Пробелы и знаки между буквами включаются вместе со следующей буквой.
- Для задания с обязательным артиклем подсказка открывает полный ожидаемый ответ, включая артикль. После полного раскрытия кнопка больше не изменяет ответ.
- Флаг подсказки сохраняется сразу, переживает очистку поля, уход в фон и восстановление текущего задания. Повторная отправка или восстановление экрана не дублируют частичный зачёт и не восстанавливают бюджет награды.
- Верно законченный ответ с подсказкой даёт частичный зачёт (N − H) / N; полное раскрытие — 0. Например, три подсказки из четырёх букв и самостоятельный ввод четвёртой дают +0,25 пункта. Уже накопленный прогресс от самих подсказок не уменьшается.
- Новая самостоятельная попытка в следующей сессии даёт +1 пункт навыка в пределах общего лимита 25.

Проверки: одно и несколько нажатий, греческая диакритика, ошибочный префикс, артикль и пробелы, полностью раскрытое слово, очистка и перезапуск после подсказки; проверяется пропорциональный зачёт и отсутствие повторного начисления.

Единые правила прогресса уточнены пользователем после разбора видео: во всех навыках самостоятельный правильный ответ +1 пункт, неправильный или пропуск −1, предел каждого навыка 0–25. Для правильного написания с подсказками действует частичный зачёт (N − H) / N; технические ошибки не штрафуются. Текущие правила имеют приоритет над ранее предложенной схемой начисления.
