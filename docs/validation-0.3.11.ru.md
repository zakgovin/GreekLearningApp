# Проверка версии 0.3.11

Причина ложной ошибки: ASR возвращал «ο φίλος», а общий валидатор ожидал «φίλος», поскольку Word.answers не содержит артикль. Введён отдельный валидатор устного ответа: принимает базовую форму и ту же форму с указанным в словаре артиклем существительного. Учитываются допустимые словарные формы и синонимы в той же категории. Ошибочный артикль и другое слово не принимаются. Написание и правила ударений не изменены.

Верный устный ответ сохраняет экран с зелёным подтверждением, распознанным текстом, греческим написанием и переводом. Пользователь переходит кнопкой «Далее»; восстановление упражнения не начисляет баллы повторно.

Регрессионный сценарий воспроизводит распознавание «ο φίλος» для вопроса «друг», проверяет +1, отсутствие немедленного перехода, отображение написания, восстановление и переход. Модульный тест проверяет три рода, базовые формы, неправильный артикль, другое слово и сохранение строгого написания.

assembleDebug, 69 Android/JVM-тестов, 7 проверок словаря и lintDebug прошли успешно. Android-сценарии выполнялись в Robolectric API 28; распознавание живой речи на физическом телефоне не проверялось. Подпись APK проверена; applicationId и ключ прежние, versionCode=25, versionName=0.3.11. Схема данных не менялась.
