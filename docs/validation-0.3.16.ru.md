# Проверка версии 0.3.16

TTS использует стандартный голос движка после setLanguage(el-GR), вместо безусловной подмены голосом с максимальным заявленным quality. Выбор установленного локального греческого голоса используется только как запасной вариант при ошибке setLanguage; проверяется результат setVoice. Успешность реальной озвучки на телефоне пользователя не подтверждена: скриншот не позволяет установить точную причину сбоя сервиса.

В сопоставлении первый сбой озвучивания отключает автоматический звук до конца текущей сессии и автоматически разблокирует упражнение. Одна Toast-подсказка заменяет повторяющиеся ошибки и кнопки. Флаг сохраняется при восстановлении Activity; новая сессия вновь пробует звук. Старые сохранённые сессии с answerAudioError переходят к продолжению без звука. При отсутствии ответа движка за 15 секунд применяется тот же сценарий. Поздние callbacks игнорируются, баллы повторно не начисляются.

Интеграционные тесты имитируют сбой, последующие верные пары без звука, восстановление Activity, завершение и точное начисление баллов. Отдельная проверка подавляет автоматический callback Robolectric, моделирует зависание и проверяет таймаут и доступность следующей пары. Существующая проверка нормальной озвучки остаётся успешной.

assembleDebug, 71 Android/JVM-тест и lintDebug прошли успешно. Подпись APK проверена; applicationId и ключ прежние, versionCode=30, versionName=0.3.16. Схема данных не менялась. Android-тесты выполнены в Robolectric API 28; физическое устройство не использовалось.
