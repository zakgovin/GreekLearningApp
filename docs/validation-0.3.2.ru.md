# Проверка версии 0.3.2

В сопоставлении правильная пара автоматически озвучивает греческую лемму. Пока идёт озвучивание, выбор блокируется. Переход блока/к итогам выполняется после onDone последней пары; промежуточный правильный ответ сохраняет текущий блок. Выход во время звука сохраняет найденные пары и возобновляет озвучку без повторного зачёта. Ошибку TTS можно повторить или явно продолжить без звука.

assembleDebug, все 56 Android/JVM-тестов и lintDebug завершились успешно. Новые сценарии проверяют текст каждого автоматически произносимого слова, блокировку новых пар до завершения, ожидание финальной озвучки перед итогом, игнорирование повторного/устаревшего callback, повтор TTS после ошибки без лишних очков. Сценарии пяти пар, перехода к остатку блока, закрытия/продолжения и старого блока из восьми пар проходят с ожиданием аудио. Android/TTS-сценарии выполнялись в Robolectric API 28 через зарегистрированный UtteranceProgressListener, без физического телефона и реального звукового вывода.
