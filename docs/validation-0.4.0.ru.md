# Проверка версии 0.4.0

Добавлены полные карточки из словаря и результатов, офлайн-примеры и формы A2. Закрытие восстанавливает список, поиск и прокрутку; сама карточка восстанавливается после пересоздания Activity. Никакие справочные формы не добавлены в валидатор ответов. Иконка — адаптивная монограмма αω.

Контент: 1724 карточки; 820 слов с готовыми цитатами Tatoeba, остальные с помеченными учебными примерами; максимум три примера. 980 таблиц существительных, 187 таблиц родов прилагательных и 241 набор трёх времён глаголов. Метод подготовки, источники и ограничения: [word-details.ru.md](word-details.ru.md). Данные морфологии генерируются корпусной библиотекой; полная независимая лингвистическая вычитка не проводилась.

assembleDebug, 74 Android/JVM-теста, 4 проверки справочных данных, 7 проверок основного словаря и lintDebug прошли успешно. Проверены все ID и лимит примеров, дословное соответствие цитат источникам, согласование составных слов, базовые неправильные формы, переключение времён, возврат в результаты без изменения сессии и чтение карточки без изменения экспортируемого прогресса. Native Graphics-рендер карточки и иконки на 360×800/API 28 просмотрен. Физическое Android-устройство в этой проверке не использовалось.

Байты основного словаря, его версии, стабильных ID и Store.kt совпадают с предыдущим коммитом: схема и код базы прогресса не менялись.
