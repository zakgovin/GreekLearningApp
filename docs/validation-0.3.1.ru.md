# Проверка версии 0.3.1

105 записей выделены в категорию «Имена собственные»; добавлены фильтр категорий словаря и отдельная группа тренировок. Обычные существительные исключают имена из вопросов, вариантов, подбора допустимых синонимов и аудиопроверки. Пользователь может добавлять собственные имена через ту же категорию.

Для 12 дополнительно размеченных названий организаций и географических объектов введён реестр стабильных идентификаторов; все 1724 ID до/после совпали. Грамматическая часть речи noun сохраняется отдельно от учебной категории, прогресс и очередь повторов не удаляются.

assembleDebug, все 54 Android/JVM-теста и lintDebug завершились успешно. Проверены изоляция категорий, фильтр словаря с переключением, запуск отдельного набора собственных имён и сохранение уже начисленного прогресса. Старые тесты пяти пар и продолжения старой сессии используют однородные обычные существительные; при продолжении прежнего смешанного блока код разделяет его на однородные участки без потери уже найденных пар. Сценарии выполнялись в Robolectric API 28, без физического телефона.

Все 7 тестов корпуса также прошли, включая реестр ID и уточнённые географические названия. Проверены 105 отметок внутри APK и совпадение упакованного словаря с исходником. Ключ и applicationId сохранены, versionCode=15, versionName=0.3.1; подпись действительна.
