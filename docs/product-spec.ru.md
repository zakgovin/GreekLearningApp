# Персональный тренажёр греческого A2

## Статус и источники

Это проектная декомпозиция по требованиям пользователя. Два формата перевода и написание по переводу My Dictionary проверены по видеозаписям пользователя; подробности и границы наблюдений — в [разборе видео](my-dictionary-video-review.ru.md). Сайт My Dictionary недоступен из среды: прокси отклоняет CONNECT с HTTP 403. PDF словаря получен от пользователя и исследован локально.

- Референс: https://play.google.com/store/apps/details?id=com.swotwords
- Основной словарь: https://www.greek-language.gr/certification/sites/greeklanguage.gr.certification/files/KLIK_A2_Ef_Glossary.pdf

Не утверждаем, что описанные ниже алгоритмы используются в My Dictionary. Выбор греческого слова по русскому значению и сопоставление проверены по видео. Написание по переводу также проверено по отдельному видео; аудирование и произношение референса пока не исследованы. Оригинальный PDF получен; условия распространения требуют отдельной проверки перед публикацией набора данных. Демонстрационные слова не должны называться официальным словарём ΚΛΙΚ A2.

## Первая версия

Офлайн-приложение Android с русским интерфейсом, греческими словами и русскими переводами. Основные сценарии: открыть словарь, выбрать тему или часть речи, изучить карточку, пройти перевод, написание, аудирование или произношение, посмотреть прогресс, добавить слова, экспортировать и восстановить данные.

Предлагаемый стек: Kotlin, Jetpack Compose, Room (SQLite), DataStore для настроек. Один локальный профиль; аккаунт и сервер для первой версии не нужны. Озвучивание через Android TextToSpeech необходимо для аудирования; требуется проверка греческого голоса и возможности его офлайн-использования. Для произношения — Android SpeechRecognizer с греческим языком и разрешением RECORD_AUDIO. Офлайн-доступность распознавания зависит от устройства: приложение проверяет её, сообщает об ограничениях и не обещает полностью офлайн-работу этого режима. Облачное распознавание допускается только с явным согласием пользователя на передачу аудио.

## Декомпозиция тренажёра

1. Словарь: поиск по греческому и русскому, фильтры по теме, части речи и прогрессу; списки «новые», «изучаются», «выучены».
2. Карточка: написание, артикль и род для существительных, часть речи, переводы, пример, тема/урок, четыре показателя навыка и общий прогресс.
3. Сессия: один из четырёх типов тренировки → группа слов → набор от 1 до 100 слов согласно настройкам выбранной тренировки → ответы и обратная связь → итог и сохранение.
4. Перевод: выбор русского значения по греческому слову, выбор греческого слова по русскому значению (до шести вариантов), сопоставление в двух колонках (до пяти пар). Все слова в вопросе, вариантах и блоке сопоставления относятся к одной части речи. Три подрежима совместно ограничены 25 пунктами навыка «Перевод».
5. Написание: русское значение с уточняющим контекстом → ввод греческого слова. Греческая клавиатура устройства; каждое нажатие «?» вводит следующую букву правильного ответа. За правильный ответ начисляется доля 1 пункта: (N − H) / N, где N — число букв ответа, H — число открытых подсказкой букв. Очистка поля и восстановление экрана не сбрасывают H.
6. Повторение: сначала слова с наступившим сроком повторения, затем слова с низким прогрессом. Освоение каждого навыка требует повторных успешных встреч.
7. Пополнение: ручное добавление и версионированный JSON-импорт; предварительный просмотр, проверка обязательных полей и дубликатов.
8. Данные: локальная база, транзакционное сохранение, миграции и резервная копия с пользовательскими словами и прогрессом.

## Правила прогресса

С учётом дополнения пользователя существуют четыре независимых навыка: перевод, написание, восприятие на слух и произношение. Каждый даёт от 0 до 25 процентных пунктов. Общий прогресс слова — сумма четырёх показателей, от 0 до 100. Повторение одного режима не заменяет освоение остальных.

Для всех четырёх навыков правила одинаковы: каждый правильный самостоятельный ответ добавляет 1 процентный пункт, каждый неправильный ответ или явный пропуск отнимает 1 пункт у соответствующего навыка этого слова. Диапазон каждого показателя — 0–25 включительно; написание допускает дробные значения из-за побуквенных подсказок. Ограничение применяется после каждого ответа, без скрытого отрицательного долга. При 25 ошибка снижает показатель до 24; при 0 ошибка оставляет 0.

Подрежимы одного навыка используют один показатель: выбор и сопоставление — translationPoints, начальное и продвинутое аудирование — listeningPoints. Прохождение всех подрежимов не увеличивает лимит навыка. Для написания с подсказкой действует исключение: правильный завершённый ответ даёт (N − H) / N процентного пункта. Подсказка уменьшает награду текущей попытки на 1/N за каждую раскрытую букву, а не дополнительно вычитает это из ранее накопленного прогресса. Полное раскрытие даёт 0. Отправленный неверный ответ до подсказки даёт −1 и не отменяется подсказкой. Технические сбои и незавершённый ввод сами по себе не являются неправильным ответом.

- Пример: перевод 25 + написание 25 + аудирование 25 + произношение 25 = 100%.
- Ошибка в любом навыке уменьшает его показатель на 1, не затрагивая остальные навыки, и планирует повторение. Поэтому общий процент слова тоже может уменьшиться. При 0 штраф не создаёт отрицательный прогресс; при 25 правильный ответ не увеличивает показатель, а неправильный снижает его до 24.
- Повторная отправка результата и повторный запуск сессии не дают дополнительных очков сверх предела навыка.
- Итоговая точность сессии и процент освоения слова — разные показатели.

### Восприятие на слух

Два подрежима заданы пользователем, оба изменяют общий listeningPoints слова, а не отдельные показатели уровней. Доступ к продвинутому режиму не требует придуманного порога: пользователь выбирает режим самостоятельно.

**Начальный:**

1. Приложение произносит греческое слово в базовой форме из проверенной леммы словаря, а не сырой записи с сокращёнными окончаниями. До ответа греческое написание скрыто.
2. Показываются русские варианты ответа — до шести, по тем же правилам, что в выборе слова. Варианты относятся к той же части речи, что и целевое слово, и не содержат неоднозначных совпадений.
3. Правильный выбор даёт +1, неправильный −1 к аудированию, с ограничением 0–25. Явный пропуск также даёт −1.

**Продвинутый:**

1. Приложение произносит греческое слово в базовой форме, не показывая его написание или русский ответ.
2. Пользователь вводит перевод по-русски и отправляет его кнопкой «Проверить» или IME Done. Незавершённый ввод не оценивается.
3. Сравнение с явно заданными допустимыми русскими переводами: NFC, без учёта регистра и крайних пробелов. Не используем произвольное сравнение по похожести; допустимые синонимы задаются в словаре. Рабочее решение: ё и е эквивалентны при проверке русского ответа, исходное написание в словаре сохраняется.
4. Правильный самостоятельный перевод даёт +1, неправильный −1. «Пропустить» считается ошибкой: −1, затем показывается правильный перевод и исходное греческое слово. Ответ остаётся до «Далее», раскрытый ответ нельзя зачесть в этой попытке.

Повторное прослушивание исходного слова доступно без штрафа — это повтор вопроса, а не раскрытие ответа. Набор с несколькими значениями должен принимать все допустимые переводы, если само аудио не задаёт контекст; нельзя требовать угадать одно из равноправных значений. До проверки у записи должны быть валидированные лемма, часть речи, произношение и русские переводы. Слова без этих данных исключаются из сессии без штрафа пользователю.

Техническая невозможность озвучить вопрос не считается ошибкой знания и не меняет прогресс. При отсутствии рабочего греческого голоса режим объясняет причину недоступности. Экранные подписи и средства доступности до ответа не должны раскрывать скрытые греческое слово или русский перевод. Сбой TTS не превращается в автоматический пропуск.

Проверки: одна базовая форма в обоих режимах; скрытый ответ; однородные варианты; несколько допустимых переводов; русская клавиатура и отправка; повтор аудио; верный/неверный ответ и пропуск ±1; общая шкала обоих режимов; границы 0 и 25; отсутствие штрафа при сбое озвучивания.

### Произношение

Сценарий задан пользователем:

1. Предъявляется русское слово или значение с необходимым контекстом. Греческий ответ скрыт.
2. Пользователь произносит перевод на греческом; приложение записывает ответ после явного нажатия кнопки микрофона.
3. Распознаватель с языком el-GR возвращает текст. Приложение показывает распознанный ответ и сравнивает его с допустимыми ответами по тем же правилам, что в написании: NFC, нормализация регистра и крайних пробелов, явные альтернативные формы и объявленное требование артикля. Тон и диерезис проверяются по общей политике написания. Никакой отдельной приблизительной проверки по сходству или выдуманного процента качества произношения нет.
4. Подсказок до ответа нет: ни греческого написания, ни образца озвучивания, ни побуквенного раскрытия. Доступна кнопка «Пропустить».
5. По нажатию «Пропустить» запись прекращается, показывается правильный греческий ответ и запускается его озвучивание. Пропуск считается неправильным ответом: показатель произношения уменьшается на 1 процентный пункт, но не ниже 0; слово ставится на повторение. Правильный ответ остаётся на экране до нажатия «Далее», чтобы его можно было прочитать и услышать.

Каждая завершённая самостоятельная голосовая попытка изменяет показатель произношения: правильная +1, неправильная −1 процентный пункт, с ограничением 0–25 после каждой попытки. Неверный ответ позволяет повторить или пропустить; новая самостоятельная запись считается новой попыткой и тоже оценивается по правилу ±1. Пропуск считается неправильным ответом и уменьшает показатель произношения на 1 процентный пункт, но не ниже 0. Повторное нажатие или запоздавший callback не должны повторять штраф для той же попытки. После раскрытия нельзя включить микрофон и зачесть повтор вслед за образцом в этой попытке. Запоздавшие результаты распознавания после пропуска игнорируются по идентификатору попытки.

Ошибка сервиса, отсутствие микрофона/разрешения или пустой результат не считаются языковой ошибкой и не меняют прогресс. Можно повторить запись либо выйти без оценки по технической причине. Явное нажатие «Пропустить» по-прежнему считается неправильным ответом и даёт −1. Если озвучивание недоступно, правильный ответ всё равно показывается с понятным сообщением о невозможности воспроизведения; текстовый показ не выдаётся за успешное аудиовоспроизведение.

Распознавание зависит от устройства, установленного сервиса и доступности el-GR. Его вывод может терять ударения или ошибаться: это нужно проверить на греческих словах до заявления о готовности режима. При строгом сравнении по правилам написания такая ошибка может привести к отклонению правильного произнесённого ответа; нельзя незаметно вводить другую нормализацию только для голоса. В интерфейсе показываем распознанный текст и даём повторить запись. Проверка распознанного текста не является объективной фонетической оценкой акцента. Аудио по умолчанию не сохраняется.

Проверки: русский вопрос без утечки греческого ответа; совпадающий и несовпадающий текст; ударение и артикль; отсутствие подсказок; пропуск до и во время записи; показ и озвучивание правильного ответа; запоздалый callback; отсутствие TTS/ASR и разрешения микрофона; штраф −1 за пропуск при положительном прогрессе, ограничение нулём и однократность штрафа.

## Однородные группы и ответы

Части речи хранятся явно: noun, verb, adjective, adverb, pronoun, numeral, preposition, conjunction, particle, phrase, unknown. Слова unknown не участвуют в групповых тренировках до разметки. Устойчивые выражения образуют отдельную группу.

Варианты перевода выбираются только из той же части речи, без совпадающих переводов и без известных допустимых значений целевого слова. Если пяти корректных отвлекающих вариантов не хватает, число вариантов сокращается; если нет ни одного — слово пропускается с объяснением. Другие части речи не подмешиваются. Русский перевод сам по себе не определяет часть речи: например, существительное «бег» и глагол «бежать» должны оставаться различными записями.

Написание: Unicode NFC, удаление крайних пробелов, приведение регистра; тон и диерезис проверяются, неверный тон показывается отдельно. Формы и альтернативные правильные ответы задаются явно, автоматическое удаление диакритики запрещено. Для существительных артикль виден на карточке; в первой версии ввод проверяет само слово, если задание явно не требует артикля. Для неоднозначного перевода добавляется контекст либо несколько допустимых ответов.

## Модель данных и обновления

- Word: стабильный id, origin (klik_a2/user), sourceVersion, lemma, article, gender, partOfSpeech, translations, acceptedSpellings, example, topic, archived.
- Progress: wordId, translationPoints, spellingPoints, listeningPoints, pronunciationPoints (каждый показатель 0–25; spellingPoints — дробный), lastCreditedAt по каждому навыку, nextReviewAt.
- Session: id, mode, startedAt, completedAt.
- Attempt: id, sessionId, wordId, submittedAnswer, correct, hintUsed, hintedLetterCount, answerLetterCount, scoreDelta, timestamp.

ID нельзя выводить из изменяемого перевода или позиции строки в PDF. Омонимы и разные части речи имеют отдельные ID. Связь с разделом/страницей источника хранится для аудита импорта.

База размещается во внутреннем хранилище приложения, вне ресурсов APK и временного кэша. При обновлении пакета с тем же applicationId и совместимой подписью данные остаются. Room выполняет явные недеструктивные миграции; fallbackToDestructiveMigration запрещён. Новая версия встроенного словаря обновляет Word по стабильному id, не заменяет базу и не перезаписывает Progress. Исчезнувшие записи архивируются с сохранением истории. Пользовательские записи не перезаписываются обновлением встроенного словаря.

Изменение прогресса выполняется в транзакции. Для всех навыков уникальный attemptId обеспечивает однократное применение как +1, так и −1: повторный callback или завершение сессии не повторяет изменение. Новая самостоятельная попытка получает новый attemptId, даже для того же слова в одной сессии. Подрежим хранится отдельно от навыка, чтобы оба уровня аудирования меняли один listeningPoints. Завершение сессии не повторяет уже применённые изменения. По уточнению пользователя неверное сопоставление уменьшает translationPoints обоих слов неверной пары на 1 у каждого, с независимым ограничением нулём. Оба изменения сохраняются одной транзакцией с одним attemptId; повторная доставка не дублирует ни один штраф. Правильная пара представляет одно слово и его перевод и даёт этому слову +1 однократно, а не +2 за две ячейки. Завершённые ответы сохраняются сразу, чтобы закрытие процесса не теряло результат. Ошибки импорта откатывают транзакцию.

Обновление не равно удалению приложения: удаление/очистка данных может уничтожить локальную базу. Для переноса и восстановления нужен пользовательский экспорт JSON с версией схемы, словарём, пользовательскими словами и прогрессом. Автоматический Android backup — дополнительный механизм, не гарантия.

## Подготовка ΚΛΙΚ A2

После получения PDF (черновое извлечение уже выполнено): сохранить метаданные источника и контрольную сумму; извлечь текст; проверить таблицы, греческую диакритику и переносы; выделить леммы, артикли, части речи и темы; подготовить и проверить перевод на русский (в оригинале только английские переводы); назначить стабильные ID; проверить вручную неоднозначные записи; сформировать версионированный набор данных и отчёт о количестве записей. До проверки нельзя обещать полный официальный словарь A2 или считать один этот глоссарий всей программой экзамена.

## Проверки готовности

- Все варианты ответа — одной части речи; недостаточный пул не приводит к подмешиванию других групп.
- Для каждого из четырёх навыков: правильный ответ +1, неправильный −1; 25 правильных от нуля дают 25; три правильных, затем два неправильных дают 1; два правильных, затем три неправильных дают 0. Дополнительно: ошибка при 0 оставляет 0; правильный при 25 оставляет 25; ошибка при 25 даёт 24.
- Пропуск уменьшает соответствующий навык на 1, но не ниже 0; техническая ошибка распознавания не меняет прогресс; повторная доставка результата одной попытки не повторяет прибавку или штраф. Подсказки других режимов не начисляют прогресс.
- Один навык не может дать более 25, итог не может превысить 100.
- Повторная отправка и перезапуск приложения не дублируют начисление.
- Проверены греческие составные Unicode-символы, регистр, тон и альтернативные ответы.

## Подтверждённые видеореференсы

[Разбор двух записей упражнений](my-dictionary-video-review.ru.md) содержит наблюдения с таймкодами, отличия от требований и правила переноса механики. В частности, вводятся выбор до шести вариантов и сопоставление до пяти пар; требование одной части речи имеет приоритет над смешанными наборами оригинала.

[Разбор записи написания](my-dictionary-writing-review.ru.md): свободный ввод по русскому значению, системная греческая клавиатура, зелёная подсветка успешного ответа; отдельно зафиксированы неопределённость автопроверки и пример со значимым артиклем. Для нового приложения проверка выполняется явно; требование артикля всегда объявляется пользователю.

Побуквенная подсказка написания уточнена пользователем: нажатие «?» открывает одну следующую букву и уменьшает возможную награду на долю 1/N пункта. За правильный ответ с H подсказанными буквами начисляется (N − H) / N пункта. Для четырёх букв: без подсказок +1, одна +0,75, две +0,5, три +0,25, четыре 0. Детальные правила и проверки — в разборе написания.

Единая формула для всех навыков: `newPoints = min(25, max(0, oldPoints + delta))`, где delta = +1 для правильного самостоятельного ответа, −1 для неправильного или явного пропуска. Техническая ошибка и незавершённая попытка без явного пропуска имеют delta = 0. Для правильного написания с подсказками delta = (N − H) / N, при полном раскрытии delta = 0. Общий прогресс слова пересчитывается как сумма четырёх текущих показателей.

## Дробный зачёт написания

N фиксируется до первой подсказки для выбранного допустимого ответа; H — число букв, реально раскрытых подсказкой, от 0 до N. Считаются буквы-графемы после Unicode NFC, без пробелов и пунктуации: ударение и диерезис не увеличивают длину. Для заданий с артиклем рабочее решение — учитывать буквы всего требуемого ответа, включая артикль; это проектное уточнение, а не отдельное требование пользователя. Нулевая длина исключается при проверке словаря.

Награда начисляется однократно после правильного завершения. Каждое нажатие меняет только бюджет награды. Ошибка или пропуск по-прежнему даёт −1 без дополнительного штрафа за подсказки. Открытые буквы и их количество сохраняются при очистке/перезапуске; подсказки не превращаются в самостоятельный ввод. После первой подсказки ожидаемый вариант ответа фиксирован, чтобы нельзя было менять знаменатель выбором синонима.

Для точности хранить прогресс и дельты как точные рациональные числа (числитель и знаменатель в строковом виде, произвольная точность), без накопительного округления 1/3 или 1/7. Округлять только отображение; состояние «25 освоено» определяется точным значением, а не округлённым текстом. Ограничение 0–25 применяется после каждой завершённой попытки. Обновление базы обязано сохранять дробные значения.

Проверки: таблица наград для N=4; три правильных с одной подсказкой при N=3 дают ровно 2 пункта; полное раскрытие даёт 0; неверный ответ/пропуск даёт −1; очистка не восстанавливает награду; повторная доставка не дублирует дробный зачёт; переполнение ограничивается 25, отрицательный результат — 0.

## Настройка размера тренировки

По требованию пользователя количество слов выносится в настройки каждой тренировки: целое от 1 до 100 включительно. Настройка отдельная для каждого подрежима (в том числе двух уровней аудирования и сопоставления), сохраняется между запусками приложения и его обновлениями. Рабочее значение по умолчанию — 10; пользователь его не фиксировал. Изменение настройки применяется к следующей сессии, текущий набор остаётся неизменным.

Число означает количество разных целевых слов в сессии, а не число вариантов ответа, ячеек или повторных попыток. В сопоставлении N слов — N пар; видимый блок до пяти пар — только разбиение большого набора на экраны и не ограничивает размер всей сессии. Число отвлекающих вариантов не изменяет количество целевых слов; они остаются той же части речи.

Если в выбранной группе доступно меньше допустимых слов, используется фактический доступный набор, а счётчик вопросов показывает фактическое количество; при уменьшении набора показывается короткое неблокирующее уведомление. Не добавлять другую часть речи или дубликаты ради достижения настройки. При нуле слов сессию не запускать, объяснить, какие данные/фильтры мешают. Одна пара в сопоставлении технически допускается; минимум настройки не увеличивается скрытым образом. Для выбора одного целевого слова отвлекающие варианты можно брать из других слов той же группы. В выборе при невозможности сформировать хотя бы два однозначных варианта задание недоступно, можно выбрать свободный ввод.

Хранить размер в DataStore по ключу trainingMode. Проверять диапазон не только в интерфейсе, но и при загрузке настроек; некорректный импорт не создаёт сессию с 0 или 101 словом. Проверки: 1 и 100, отказ для 0/101/дробного значения, независимые настройки режимов, перезапуск и обновление, малый словарь, однородность групп, сопоставление с разбиением на блоки.

Проверки штрафа сопоставления: у слов A=3 и B=2 после неверной пары A=2, B=1; при A=0 и B=2 результат A=0, B=1. Повторная доставка события не изменяет эти результаты. Штраф затрагивает только навык перевода каждого слова, а не другие навыки.

## Переход после ответа

После правильного ответа во всех режимах сразу сохраняется прогресс и показывается следующее слово без промежуточного экрана и кнопки «Далее». Это относится и к правильному написанию с частичным зачётом. После последнего задания открывается итог тренировки. При ошибке или пропуске правильный ответ остаётся на экране до «Далее»; показ и озвучивание после пропуска произношения сохраняются. Старый сохранённый экран правильного ответа при продолжении сессии также автоматически пропускается.

## Выбор ответа: повтор до успеха и озвучивание (версия 0.1.2)

Уточнение пользователя имеет приоритет над правилом немедленного перехода из 0.1.1 для режимов выбора: перевод в обоих направлениях и начальное аудирование.

- Неправильный вариант краснеет на том же экране. Правильный ответ не раскрывается; пользователь выбирает снова до успеха. Уже отклонённая кнопка недоступна для повторного нажатия, чтобы двойной тап не снимал очки дважды. Остальные варианты и порядок сохраняются, в том числе после возврата в сессию.
- За каждый новый неверный выбор снимается 1 пункт у текущего слова, за правильный добавляется 1. После ошибок правильный выбор всё равно даёт свой +1 в соответствии с общей формулой.
- После правильного выбора кнопки блокируются, правильная становится зелёной, автоматически звучит греческая лемма. Нового экрана результата и кнопки «Далее» нет. Следующее задание появляется только по подтверждённому TTS onDone именно этой озвучки; после последнего задания — итог.
- Повторные нажатия, устаревшие callbacks и возвращение в приложение не повторяют начисление. При прерывании озвучки правильного ответа возобновление сессии повторяет озвучку, но не награду.
- Технический сбой или отсутствие голоса оставляет результат сохранённым и показывает внутри текущего вопроса «Повторить озвучивание» и «Продолжить без звука». Последнее — явный выход из технического тупика, без нового зачёта/штрафа.
- Явный пропуск остаётся отдельным действием −1 с раскрытием ответа по ранее установленным правилам. Исправление ошибочного выбора не требует пропуска.
- Это изменение относится к кнопочным вариантам ответа; написание, свободный ввод, произношение и сопоставление сохраняют ранее описанные сценарии.

## Ошибки при нулевом прогрессе (0.2.3)

Чтобы ошибка на нуле не исчезала перед правильным ответом, внутри одной тренировки сохраняется расчётный баланс каждого слова и навыка. Он может учитывать ещё не компенсированные ошибки, но отображаемый/накопленный прогресс остаётся 0–25. Ошибка при 0, затем правильный ответ дают 0, а не +1; две ошибки, затем три правильных дают 1. Баланс и прогресс обновляются атомарно, повторные события не повторяют штраф. При выходе и продолжении той же тренировки расчёт сохраняется; новая тренировка начинается от текущего неотрицательного прогресса без переноса некомпенсированных ошибок старой сессии. Положительный запас выше 25 не накапливается: правильный при 25 оставляет 25, следующая ошибка снижает до 24. Общие правила применяются ко всем навыкам. Схема базы 3 добавляет служебные балансы без удаления прежних данных.

## Закрепление ошибок (0.2.4)

Каждое слово с неправильным ответом или явным пропуском ставится в постоянную очередь своего конкретного режима. Исправление в той же сессии не отменяет повтор. Очередь включается приоритетно при следующем запуске этого режима для выбранной части речи; остальные места заполняются случайно, итоговый порядок перемешан. В сопоставлении неверная пара ставит оба слова в очередь. Ограничение 1–100, однородность группы и однозначность пар сохраняются: избыток и временно несовместимые слова остаются до следующей подходящей тренировки, а не теряются.

Самостоятельный правильный ответ в последующей сессии снимает запись из очереди. Новая ошибка переносит её на следующую сессию; подсказанный ответ не снимает очередь. Выход/продолжение той же сессии не считается новой тренировкой. Очередь сохраняется при перезапуске и включается в JSON-резервную копию. Добавление/снятие выполняется в одной транзакции с начислением и защищено attemptId от повторного события. Схема 4 добавляет таблицу очереди без изменения прежнего прогресса и расчётных балансов.

## Крестик справа (0.2.5)

По последнему уточнению пользователя крестик выхода во всех семи упражнениях расположен в верхнем правом углу, вместо левого. Верхняя строка явно имеет направление слева направо: название приложения слева, крестик справа. Размер области нажатия и сохранение текущей тренировки не меняются.

## Спокойный компактный интерфейс (0.3.0)

Итоги отображаются единым списком с тремя колонками вместо больших карточек. Проценты и изменения сохранены, визуальный шум (отдельные полосы и повтор «Было») убран. Уплотнены отступы, заголовки и кнопки, минимальные области нажатия 48 dp сохранены. Переходы между экранами и вопросами — короткие fade/сдвиг на 6 dp, без игровых эффектов, с учётом системного отключения анимаций. Повторное состояние одного вопроса не анимируется; логика обучения не зависит от анимаций.

## Отдельная категория имён собственных (0.3.1)

105 записей с именами собственными (личные имена, страны, города и именованные объекты/организации) вынесены в категорию «Имена собственные». В словаре добавлен фильтр категорий; в обычных существительных эти записи не отображаются и не используются ни вопросами, ни отвлекающими вариантами. Категория доступна для отдельной тренировки и ручного добавления слов. Во всех проверках синонимов и аудирования категории изолированы.

Грамматическая часть речи в данных остаётся noun; категория вычисляется по properName, чтобы не менять прежние словарные ID. Для уточнённой разметки объектов добавлен постоянный реестр идентификаторов: все 1724 ID сохранены, прогресс, история, активные сессии и очереди не удаляются. Очереди имён теперь отбираются только при выборе категории имён, остальные существительные тренируются отдельно. При продолжении старой смешанной сессии варианты фильтруются по категории текущего слова, а сопоставление разбивается на однородные блоки.

## Озвучивание сопоставления (0.3.2)

После каждой правильной пары автоматически произносится греческая лемма. До окончания озвучивания новые пары не выбираются, а последний правильный ответ блока/сессии остаётся виден. Следующий блок и итог открываются только после TTS onDone текущего слова. При закрытии во время озвучки она возобновляется после продолжения, без повторного начисления. Ошибка звука даёт повтор и явное продолжение без звука на том же экране.

## Красная подсветка неверной пары (0.3.3)

Обе выбранные ячейки неверного сопоставления подсвечиваются красным на 500 мс, затем возвращаются к обычному виду и доступны для новой попытки. Правильные ранее найденные пары остаются зелёными. Пока отображается ошибка, новые нажатия не оцениваются; повторные/устаревшие события не дают дополнительных штрафов. Текстовое объяснение остаётся доступным независимо от цвета. Выход и продолжение во время подсветки сохраняют штраф, но не оставляют кнопки заблокированными; отложенный сброс не возвращает пользователя из главного экрана обратно в упражнение.

## Единая навигация закрытия (0.3.4)

На экранах словаря и выбора упражнения кнопка «На главную» заменена крестиком в верхнем правом углу. С главного экрана удалён отдельный вход в настройки количества слов; настройки открываются через «Настроить количество слов» при выборе упражнения. После сохранения или закрытия настроек пользователь возвращается к выбору упражнения с сохранёнными выбранной группой и режимом. Обычные упражнения по-прежнему закрываются крестиком с сохранением сессии.

## Подтверждение правильного написания (0.3.5)

Правильно заполненное поле становится зелёным и временно недоступно для редактирования. Автоматически произносится принятый греческий ответ, в том числе допустимый синоним; переход к следующему вопросу/итогу — по окончании TTS. Частичный зачёт подсказок сохраняется. Повтор озвучки после ошибки/прерывания не начисляет дополнительные очки. При недоступном звуке доступны прежние повтор и явное продолжение без звука; отдельного экрана правильного ответа нет.

## Пропуск только в двух режимах (0.3.6)

В начальном аудировании и написании кнопка пропуска удалена. В выборе перевода, выборе слова и сопоставлении её также нет по предыдущим уточнениям. Пропуск остаётся только в продвинутом аудировании и произношении, по прежним правилам −1. При пустом вводе написания сообщение больше не предлагает несуществующую кнопку; проверка не меняет прогресс.

## Стабильный блок аудирования и чёткая речь (0.3.7)

В начальном аудировании правильный выбор раскрывает греческое написание на месте кнопки «Прослушать слово», с сохранением высоты блока. Варианты сохраняют порядок и координаты при подтверждении. До ответа написание скрыто. Для TTS предпочтителен качественный установленный локальный голос el-GR, темп 90%, естественный pitch 1; чужой язык и отсутствующие модели не подставляются. Качество реального произношения зависит от движка телефона, приложение не заменяет его собственной фонетической моделью.

## Подтверждение продвинутого аудирования (0.3.8)

Правильный русский перевод подсвечивается зелёным и временно недоступен для редактирования. Автоматически произносится исходное греческое слово, не введённый русский текст. Переход — после завершения озвучивания, включая последнее слово перед итогом. Кнопка прослушивания сохраняет своё место и блокируется, чтобы поле не прыгало и воспроизведение не прерывалось повторным нажатием. Повтор звука/выход и продолжение не дают новых очков. До ответа пропуск остаётся доступен по прежним правилам.
