# Проверка версии 0.3.8

В продвинутом аудировании правильный русский перевод остаётся в поле ввода, поле подсвечивается зелёным и блокируется. Затем озвучивается греческое слово. Переход к следующему вопросу выполняется после завершения озвучивания. Кнопка воспроизведения сохраняет место на экране. Во время подтверждения проверка и пропуск недоступны.

Два новых теста проверяют зелёное поле, русский текст и греческую озвучку, ожидание окончания звука, переход ровно на один вопрос, защиту от запоздалого callback, повтор озвучивания после сбоя и восстановление после пересоздания Activity без повторного начисления баллов.

assembleDebug, 66 Android/JVM-тестов, 7 проверок словаря и lintDebug прошли успешно. Android-сценарии выполнялись в Robolectric API 28; на физическом телефоне эта версия не проверялась.
