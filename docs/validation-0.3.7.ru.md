# Проверка версии 0.3.7

В начальном аудировании после правильного выбора на месте кнопки воспроизведения появляется греческая лемма. Место не удаляется: высота одинакова до/после раскрытия и учитывает размер шрифта для двух строк, поэтому варианты не поднимаются вверх. Порядок вариантов сохранён. До правильного выбора написание не раскрывается.

TTS остаётся греческим el-GR, предпочитает установленный локальный голос с высоким quality, затем низкой latency, без голосов другого языка и требующих установки. При отсутствии подходящего кандидата сохраняется стандартный греческий голос движка. Темп 0,90, pitch 1,0, AudioAttributes CONTENT_TYPE_SPEECH/USAGE_MEDIA; громкость не меняется. Фактическая разборчивость и произношение зависят от установленных движка и модели на телефоне, на физическом устройстве не оценивались.

assembleDebug, все 64 Android/JVM-теста и lintDebug завершились успешно. Новый Native Graphics-сценарий на 360×800 px проверяет отсутствие греческого ответа до выбора, раскрытие после, одинаковую высоту/позицию блока и точное совпадение top/height каждого варианта. Дополнительный тест выбора голоса исключает English, network-only и notInstalled модели, выбирая качественный локальный греческий голос. Android-сценарии выполнялись в Robolectric API 28.
