# Проверка версии 0.2.4

Добавлена постоянная очередь закрепления отдельно для каждого режима. Ошибки/пропуски ставят слово в очередь; неправильное сопоставление — оба слова. Исправление в исходной сессии не отменяет повтор. При следующем запуске выбранного режима для той же части речи очередь приоритетна, остальные слова случайные, окончательный порядок перемешан. Независимый правильный ответ в последующей сессии снимает запись; новая ошибка продлевает повтор. Переполнение размера и неоднозначные пары остаются в очереди до подходящего запуска.

assembleDebug, все 50 Android/JVM-тестов и lintDebug завершились успешно. Новые проверки: очередь после ошибки+исправления сохраняется; режимы изолированы; перезапуск сохраняет очередь; независимый успех в новой сессии снимает запись; оба слова неверной пары входят в очередь; JSON-резервная копия восстанавливает очередь; отбор соблюдает приоритет/размер/группу и не дублирует слова; реальный запуск «Выбрать слово» с размером 1 включает ошибочное слово прежде случайных; миграция схемы 3→4 сохраняет расчётные балансы и прогресс. Ранее проверяемые миграции 1/2 также проходят до версии 4. Сценарии Android — Robolectric API 28.

Добавление/снятие очереди выполняется в транзакции с начислением и дедупликацией attemptId. Подпись APK действительна, ключ и applicationId сохранены, versionCode=12, versionName=0.2.4. Физическое устройство не использовалось.
