# Ελληνικά · A2

Персональный Android-тренажёр греческой лексики. Приложение на Kotlin, со стандартным Android UI и SQLite, без сервера и аккаунта. Android 8.0+ (API 26), сборка под API 35.

## Возможности

Полные карточки открываются из словаря и результатов: до трёх примеров с переводом, падежи существительных, роды прилагательных, лица и три времени глаголов. [Источники, метод подготовки и ограничения](docs/word-details.ru.md).


- Словарь, поиск, ручное добавление, JSON-импорт, экспорт слов и прогресса.
- Перевод в двух направлениях и сопоставление. Неверная пара снимает по 1 пункту у обоих слов.
- Написание греческого слова по русскому значению. Побуквенная подсказка; правильный ответ даёт долю `(буквы − подсказки) / буквы` от одного пункта.
- Начальное аудирование с выбором русского перевода; продвинутое с вводом перевода. Общий показатель навыка.
- Произношение: русский вопрос → греческий ответ голосом; пропуск показывает и озвучивает ответ.
- Правильный самостоятельный ответ +1, ошибка/пропуск −1; четыре навыка по 0–25 пунктов, суммарно 0–100%. Дроби хранятся точно.
- Отдельные настройки 1–100 слов для каждого режима. Варианты и группы сопоставления относятся к одной части речи.
- В выборе ответа неверная кнопка краснеет, можно пробовать дальше. Правильный выбор автоматически озвучивается по-гречески; после окончания звука появляется следующее слово, после последнего — итог.
- Написание принимает правильный артикль или его отсутствие; после верного ввода поле зеленеет, звучит слово. Верный устный ответ показывает написание и ожидает «Далее».
- В сопоставлении сбой TTS не блокирует занятие: сессия автоматически продолжается без звука.
- На итоговом экране изменение стоит перед общим прогрессом; кнопки закреплены внизу.
- Сохранение ответов, черновика и использованных подсказок; продолжение незавершённой сессии.

## Сборка

Открыть проект в Android Studio, установить JDK 21 и Android SDK Platform 35 / Build Tools 35.0.0, затем:

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

На обычной машине SDK можно указать в **локальном, не отслеживаемом** `local.properties` (`sdk.dir=…`). Gradle Wrapper проверяет SHA-256 дистрибутива.

В облачной среде `/workspace`:

```sh
python tools/setup_android.py
python tools/test_a2_dictionary.py
python tools/gradle_cloud.py :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Подготовка использует официальные архивы с проверкой контрольных сумм. Полный JDK/SDK и Gradle устанавливаются вне репозитория, в `/workspace/toolchains`. Сборка использует существующий сетевой прокси и системное хранилище доверенных сертификатов, без отключения TLS-проверки.

APK: `app/build/outputs/apk/debug/app-debug.apk`. Это тестовая debug-сборка, не публикация в Google Play. Установка через Android/ADB:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Для обновления поверх установленной версии сохраняйте applicationId и ту же подпись. Облачный debug-ключ хранится вне репозитория в `/workspace/toolchains/android-user/debug.keystore`; он должен сохраняться вместе со средой. На другой машине стандартный debug-ключ будет другим. Для постоянного распространения нужен отдельный постоянный ключ подписи. Не удаляйте приложение ради обновления: удаление и очистка данных уничтожают локальные данные. Резервную копию можно сохранить через главный экран.

## Данные и ограничения первой версии

В APK встроены **1724 учебные записи**: полный глоссарий из присланного PDF (1704 лексические статьи, после нормализации и разделения форм — 1721 запись) и 3 сохранённые стартовые записи. Русские переводы и грамматическая разметка подготовлены для приложения; это не официальное русское издание. [Полнота, происхождение и подготовка словаря](docs/a2-dictionary.ru.md).

Все прежние 60 ID сохранены. Миграция базы 1 → 2 добавляет служебную таблицу и сливает словарь без удаления прогресса, истории и пользовательских слов. Средний процент может снизиться из-за новых неизученных слов; проценты прежних слов не сбрасываются. Словарь доступен поиском и страницами по 40 записей.

Формат словаря для импорта показан в `app/src/main/assets/a2.json`; `starter.json` сохранён как исходный набор для совместимости и тестов миграции. Корень: `schemaVersion: 1`, `words: [...]`; каждая запись содержит стабильный `id`, `greek` (базовая форма), `russian` (массив допустимых переводов), `partOfSpeech`, необязательные `article`, `forms`, `source`. Импорт словаря не перезаписывает прогресс, если файл не содержит секции `progress`. Полная резервная копия также содержит прогресс, историю попыток и настройки; восстановление заменяет указанные показатели совпадающих ID после предупреждения. Слова объединяются, не удаляются.

Греческое TTS и распознавание el-GR предоставляются Android. Для аудирования нужен установленный греческий голос. Произношению нужны микрофон и сервис распознавания; перед его первым использованием приложение объясняет возможную сетевую обработку и получает согласие. Офлайн-распознавание запрашивается, но зависит от сервиса. Само приложение аудио не хранит. Качество TTS/ASR и установка обновления APK должны быть проверены на реальном устройстве; автоматические тесты этого не заменяют.

База версии 4 обновляется недеструктивно: повторная загрузка стартового словаря не заменяет прогресс или пользовательские записи. Для будущих изменений схемы необходима явная миграция; автоматического удаления базы при несовместимой версии нет. Стабильные ID нельзя перенумеровывать при обновлении словаря.

Новые тренировки выбирают случайный набор из всей выбранной части речи, без повторов; при продолжении набор сохраняется. Календарный алгоритм интервальных повторений пока не реализован.
